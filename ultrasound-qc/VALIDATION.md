## 真实 OCR

本地处理医院样例，没有上传医院报告文字或图片。以下是单次测量，不作为延迟保证。

| 模式 / 类别 | 结构结果 | 测量耗时 |
|---|---|---|
| GPU 介入造影 | 15个文本块 | 5531 ms |
| GPU 心脏 | 70块，其中59单元格；坐标对应数量不一致，要求核对 | 1532 ms |
| GPU 腹部浅表 | 10块；低置信度，要求核对 | 297 ms |
| GPU 血管 | 51块，其中46单元格；低置信度，要求核对 | 453 ms |
| CPU 介入造影 | 15个文本块 | 24578 ms |
| CPU 心脏表格 | 70块，其中59单元格；结构关系要求核对 | 39609 ms |

GPU缓存后的初始化实测19.42秒，CPU6.72秒；初次模型下载约221秒初始化，受网络影响。数据来自 `.runtime/verification/summary-gpu.json` 和 `summary-cpu.json`。

发现UVDoc矫正会裁掉部分截图边缘标题/结论，因此当前默认关闭。表格保留行列、空单元格和合并跨度；无法证明单元格坐标对应时暂停外发，不强行修正。

扩展抽取每类10张、共40张截图，在本机GPU重新识别，40/40完成，无外发。部位、所见和结论均提取到；17张无自动确认原因，23张因低置信度、结构或标题恢复警告要求核对。这不是字符准确率，也不说明17张报告医学质控通过。

| 介入、造影 | 10/10 | 0 |
| 心脏 | 10/10 | 9 |
| 腹部浅表 | 10/10 | 5 |
